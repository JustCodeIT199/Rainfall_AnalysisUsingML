# 🌧️ Rainfall Analysis Using Machine Learning

This project focuses on analyzing and predicting rainfall patterns using various machine learning techniques. Implemented in Python with the help of Jupyter Notebook, it provides statistical insights and model-based forecasting using historical rainfall data.

## 🎯 Objective

To leverage machine learning models to analyze historical rainfall data and make predictions that can help in planning agriculture, water resource management, and climate research.

## 🧠 Machine Learning Models Used

- 📈 **Linear Regression**
- 🌲 **Random Forest Regressor**
- 🤖 **Decision Tree**
- 📉 **Support Vector Regression (SVR)**

## 📊 Libraries & Tools

- **Data Processing**: `pandas`, `numpy`
- **Visualization**: `matplotlib`, `seaborn`
- **Machine Learning**: `scikit-learn`
- **Notebook**: Jupyter Notebook

## 📁 Project Structure

Rainfall_AnalysisUsingML/ ├── main_project_sem4.ipynb # Main analysis notebook ├── rainfall_dataset.csv # Input data (if available) ├── requirements.txt # Python dependencies └── README.md # Project documentation


## 📌 Features

- Exploratory Data Analysis (EDA) on rainfall dataset
- Visualization of trends and correlations
- Model training and evaluation (R² score, MAE, RMSE)
- Comparative performance analysis of different models
- Prediction on unseen data

## 🚀 How to Run

1. **Clone the Repository**
   git clone https://github.com/JustCodeIT199/Rainfall_AnalysisUsingML.git
   cd Rainfall_AnalysisUsingML
   
Set up a virtual environment (optional but recommended) .
python -m venv env .
source env/bin/activate . # On Windows: env\Scripts\activate .

Install Required Libraries
pip install -r requirements.txt

Launch Jupyter Notebook
jupyter notebook main_project_sem4.ipynb
